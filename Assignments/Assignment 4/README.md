## Compile/run
For each standalone source file, open a terminal in its task folder:
```sh
javac FileName.java
java ClassName
```
Swing programs require a desktop graphical environment. Task 6 additionally requires MySQL, MySQL Connector/J on the classpath, execution of `Task06/schema.sql`, and DB_URL, DB_USER, DB_PASSWORD environment variables.
