# Java Programming — Assignment 3 (CO3)
## Exception Handling and Multithreading

This folder contains one Java source file for each question Q1–Q7.

### Task index
| Question | Source file | Main concepts |
|---|---|---|
| Q1 | Task01/ATMWithdrawal.java | Input validation, exceptions, finally |
| Q2 | Task02/StorageDemo.java | User-defined checked exceptions and chaining |
| Q3 | Task03/SalesReport.java | Manual closing and try-with-resources |
| Q4 | Task04/ScannerStations.java | Thread, Runnable, start, sleep, join, isAlive |
| Q5 | Task05/SeatBooking.java | Race conditions and synchronized booking |
| Q6 | Task06/TokenCounter.java | Producer-consumer, wait/notifyAll, ordered wallet locks |
| Q7 | Task07/ResultProcessor.java | ExecutorService, Callable, Future, concurrent collection |

### Compile and run
Use JDK 17 or later. Open a terminal in the task folder, then compile and run the class. Example:
```sh
cd "Assignments/Assignment 3/Task02"
javac StorageDemo.java
java StorageDemo
```
Use the corresponding source filename and public class name for each question.
