javac src/PlaylistCollectionsBenchmark.java

## Coverage

Benchmarks ArrayList and LinkedList for end adds, front inserts, indexed access and iteration at 1k, 10k and 50k sizes. ArrayDeque is used for double-ended Up Next.

Run on the Java version installed in your lab. Benchmark timings vary by JVM, warm-up, hardware and system load; execute multiple times and retain raw measurements for your report.
